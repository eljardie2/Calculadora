# Calculadora

Aplicación web para realizar operaciones matemáticas y cálculos geométricos (área y perímetro).

## Funcionalidades

### Operaciones matemáticas

- Suma
- Resta
- Multiplicación
- División

### Figuras geométricas

| Figura      | Área              | Perímetro        |
| ----------- | ----------------- | ---------------- |
| Círculo     | π · r²            | 2 · π · r        |
| Cuadrado    | l²                | 4 · l            |
| Rectángulo  | b · h             | 2 · (b + h)      |
| Triángulo   | (b · h) / 2       | l₁ + l₂ + l₃     |

## Uso local

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador (doble clic o arrastrar al navegador).

No requiere instalación ni servidor.

## Estructura del proyecto

```
Calculadora/

├── styles.css    # Estilos
```
